# BUILD 078 — repertoire sources

The bank now contains **350 entries: 200 jazz, 50 rock, 100 classical**.
`melody-bank.mjs` combines independently reproducible source modules.

## Rock — 50 vocal melodies

Source: Trevor de Clercq and David Temperley, [Rock Corpus](https://rockcorpus.midside.com/).
[Download and notation](https://rockcorpus.midside.com/melodic_transcriptions.html),
[conversion semantics](https://rockcorpus.midside.com/programs.html).
Corpus data licence: CC BY 4.0, as stated by its authors. The transcriptions
represent the vocal line, not famous instrumental riffs or original recordings.

Run `python3 game/tools/import_rock_melodies.py /tmp/smc-rock-melodies.zip`.
The archive URL and SHA-256 of each selected file are in ROCK_050_SOURCES.json.
The converter checks every output MIDI pitch and onset against the downloaded
NLT file. Source absolute timings are preserved through a 60-BPM event clock.
Source note offsets do not exist: articulation is explicitly estimated using
min(one bar, next onset), following the corpus method. Long gaps remain rests.
The opening eight source measures form the preview; the full vocal line is
available after recognition. These are symbolic renditions, not recordings.

## Classical — 100 selected score reductions

- 35 works from [MuseTrainer's public-domain MusicXML library](https://github.com/musetrainer/library).
  One edition per work, with source file hashes. Misattributed “Chopin Spring
  Waltz” / Mariage d'Amour editions were excluded. Gymnopédie uses the melodic
  second voice; other piano extracts use the upper staff's first voice.
- 65 works from [DCMLab](https://github.com/DCMLab): Schumann Kinderszenen (13),
  Tchaikovsky Seasons (12), Grieg Lyric Pieces (21), Mozart sonata openings (18),
  Debussy Suite bergamasque (1). These corpus adaptations are distributed under
  **CC BY-NC-SA 4.0**, matching their source; retain this attribution and licence.
  They are suitable for this noncommercial test release. A commercial release
  must replace these data or obtain permission; the licence is not CC0.
  Attribution: Hentschel, Rammos, Neuwirth, Moss & Rohrmeier (2024),
  *An annotated corpus of tonal piano music from the long 19th century*,
  https://doi.org/10.18061/emr.v18i1.8903 ; Mozart corpus contributors at
  https://github.com/DCMLab/mozart_piano_sonatas .

CLASSICAL_100_SOURCES.json lists individual files, SHA-256 hashes, licences,
voices/reduction method and generated titles. `tools/import_classical_melodies.py`
reads the source score/table (exact pitch, onset, duration and tie information).
Simultaneous chords are reduced to their highest note in the selected voice.
Repeats are not expanded. “Full theme” means the complete written selected voice.
35 familiar concert/teaching favourites lead the bank; the later portion includes
more advanced piano repertoire, not a claim that all 100 are equally famous.
The level pools and Intelligence introduce the later works progressively.

To reproduce: download the MuseTrainer master archive and DCMLab main archives
for schumann_kinderszenen, tchaikovsky_seasons, grieg_lyric_pieces,
mozart_piano_sonatas and debussy_suite_bergamasque to the `/tmp/smc-*.zip` names
in the importer, then run `python3 game/tools/import_classical_melodies.py`.
Raw downloaded archives are not committed. No reference PDFs are published.

## Earlier jazz bank (200)


`melodies-catalog.mjs` is generated by `tools/import_melodies.py`. The source
score archives are deliberately kept outside the public repository.

- 130 lead sheets: PSjazzEval RealBook evaluation corpus, each MusicXML file
  marked CC BY 4.0.
- 48 lead sheets: Freed Jazz MuseScore archive; source and public-domain notes
  are retained in each downloaded score.
- 22 lead sheets: OpenEWLD public-domain MusicXML collection.

The generated catalog stores one monophonic line as relative semitone and beat
durations, including rests, pickup bars, tuplets and ties. Every record also
keeps a stable ID, the source file name and its SHA-256 digest so a questionable
theme can be traced back to the exact imported score. Source archives and PDFs
are not shipped with the public application.

Melody Memory plays an 8-bar excerpt (16 bars only when the first eight contain
too few pitched events). After a correct answer, it plays the complete linear
form written in the imported score. Repeat signs and road-map instructions are
not expanded into a performed arrangement, so “complete” here means all written
events available to the importer rather than an interpreted club performance.

The 200 entries pass structural checks for title uniqueness, usable melodic
material, finite pitch/duration events and source parsing. They are symbolic
imports, not 200 individually approved transcriptions. `All the Things You Are`
was additionally checked against the user's Real Book at the opening of the
head; this exposed and replaced the former inaccurate hand-coded excerpt.

The user's local Real Book PDFs under `/Users/tim/Documents/_SCRIBD/Standards`
are reference copies for visual checks and are never copied into Git.
