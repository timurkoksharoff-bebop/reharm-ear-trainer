# Melody Memory source record

`melodies-catalog.mjs` is generated by `tools/import_melodies.py`. The source
score archives are deliberately kept outside the public repository.

- 130 lead sheets: PSjazzEval RealBook evaluation corpus, each MusicXML file
  marked CC BY 4.0.
- 48 lead sheets: Freed Jazz MuseScore archive; source and public-domain notes
  are retained in each downloaded score.
- 22 lead sheets: OpenEWLD public-domain MusicXML collection.

The generated catalog stores one monophonic line as relative semitone and beat
durations, including rests, pickup bars, tuplets and ties. Every record also
keeps a stable ID, the source file name and its SHA-256 digest so a questionable
theme can be traced back to the exact imported score. Source archives and PDFs
are not shipped with the public application.

Melody Memory plays an 8-bar excerpt (16 bars only when the first eight contain
too few pitched events). After a correct answer, it plays the complete linear
form written in the imported score. Repeat signs and road-map instructions are
not expanded into a performed arrangement, so “complete” here means all written
events available to the importer rather than an interpreted club performance.

The 200 entries pass structural checks for title uniqueness, usable melodic
material, finite pitch/duration events and source parsing. They are symbolic
imports, not 200 individually approved transcriptions. `All the Things You Are`
was additionally checked against the user's Real Book at the opening of the
head; this exposed and replaced the former inaccurate hand-coded excerpt.

The user's local Real Book PDFs under `/Users/tim/Documents/_SCRIBD/Standards`
are reference copies for visual checks and are never copied into Git.
