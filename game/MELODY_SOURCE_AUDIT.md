## Найденный практически доступный источник

[Freed Jazz](https://freedjazz.org/) публикует 52 джазовые темы: PDF и исходник
MuseScore Studio. Среди них Body and Soul, Embraceable You, Georgia On My Mind,
I Got Rhythm, Stardust, Softly As in a Morning Sunrise, Blue Skies,
Bye Bye Blackbird, The Man I Love. Это нотные темы, а не транскрипции соло.

Реально скачан и разобран ZIP/XML образец:

- Страница: https://freedjazz.org/songs/body-and-soul/
- Файл: https://freedjazz.org/songs/body-and-soul/body-and-soul.mscz
- Локальный исследовательский файл: `/private/tmp/smc-body-and-soul.mscz`.
- Внутри `body-and-soul.mscx`, MuseScore 4.70; название и автор Johnny Green
  присутствуют в метаданных. Одна нотная строка, 32 такта, 130 нотных событий,
  15 пауз, 3 элемента Tuplet. Присутствуют абсолютные MIDI-высоты, длительности,
  текст и гармония. Это достаточно для написания детерминированного импортера.
- Другие открытые исходники с той же структурой URL:
  https://freedjazz.org/songs/georgia-on-my-mind/georgia-on-my-mind.mscz и
  https://freedjazz.org/songs/softly-as-in-a-morning-sunrise/softly-as-in-a-morning-sunrise.mscz.
  Они обнаружены на страницах, но не скачаны в этой проверке.

Сайт объявляет собственную работу общественным достоянием в США. Страницы

- https://huggingface.co/datasets/PRAIG/JAZZMUS_staffLevel

вход и согласие на передачу контактных данных для запроса доступа. Лицензия
набора CC BY-NC 4.0. Файлы из набора не скачивались: не обходить ограничение
и не считать карточку датасета разрешением на доступ. Для полных тем лучше
исходный JAZZMUS, поскольку staffLevel разделён на системы.

## Запасной открытый MusicXML

[OpenEWLD](https://github.com/00sapo/OpenEWLD) — MXL с мелодией и гармонией;
автор отобрал произведения, которые считает общественным достоянием.
Метаданные имеют смешанные лицензии; README перечисляет известные ошибки
сохранения тональности и размера. Не использовать без проверки.

Полное дерево реально скачано в `/private/tmp/smc-openewld-tree.json`:
502 файла MXL, ответ API не усечён. Есть Sweet Georgia Brown, Embraceable You,
I Got Rhythm и Fascinating Rhythm. Общая коллекция не равна 502 джазовым темам.

## Проблемы текущей модели воспроизведения

`game/audio.mjs` → `melody()` принимает только `notes` и `beats`, играет каждый
элемент как ноту и фиксирует темп около 125 BPM. Сейчас нет представления пауз,
лиг и артикуляции. Перенос исходника с пропуском пауз опять исказит узнаваемый
ритм. Прямое извлечение только высот из XML недостаточно.

В текущем Greensleeves первые высоты `[9,0,2,...]` переходят вниз на большую
сексту. Данные не фиксируют необходимый переход в следующую октаву; дробные
beats также не являются точной нотной транскрипцией. Исправлять по выбранному
источнику, а не ещё раз угадывать знакомую мелодию. All the Things You Are
пока не сверен: комментарий про прежнюю проверку Real Book не доказывает,
что текущая версия звучит правильно.

## Конкретный следующий шаг

1. Написать импорт одного нотного голоса из MSCX/MusicXML с точными высотами,
   паузами, затактом, точками, триолями и объединением лиг. Отклонять
   неподдержанные конструкции с диагностикой. Прототип — скачанный Body and Soul.
2. Доработать проигрыватель для пауз и длительностей; не переатаковывать ноту,
   связанную лигой. Сверить первые 4–8 тактов с PDF, затем прослушать.
3. Загружать следующие темы порциями, сохранять источник/номер тактов/дату
   проверки для каждой. Предлагать пользователю контрольный экран прослушивания.
   Только проверенные темы включать в игровую ротацию.
4. Для современных стандартов, которых нет в подходящем открытом наборе,
   принимать предоставленные пользователем MusicXML с мелодией. Jazz1460 из
   iReal содержит гармонию и не восполняет нотную линию.

Исследование не меняет канонический каталог, игровые мелодии или аудио.
Исходные нотные файлы остались в `/private/tmp`, в Git их не добавлять.
