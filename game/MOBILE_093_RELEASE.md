# Mobile 0.93.1

Published from the local 0.93 development distribution. The public game directory contains the frozen standalone build, not the development workspace.

- Permanent right-hand core chord rail; required rare qualities appear separately.
- Transparent collapsible lotus inventory, outside-click dismissal and active repeat indicator.
- Current-chord repeat in tempo, including activation during tonic reference.
- Navigation charges drop less often; collected charges are consumed by jumps.
- Pause controls separate from resource gauges; accompaniment stop buttons on the left.
- Wrong answers cost 3 resource points; colored nonfatal meteor impacts have 15% stronger targeted damage.
- Arrangement flowers retain their shape with quieter opacity and no rhythm/round captions.
- Touch gesture protection is bundled; portrait locking remains platform-dependent.

Validation: canonical Trainer smoke tests (239 progressions), book-route palette checks (107 routes), targeted repeat/damage regression checks, release-scoped offline cache test, browser launch check.

Cache IDs: space-music-college-0.93.1-mobile1 and reharm-ear-trainer-v0.93.1-mobile1. Reference PDFs and private material are excluded. Existing Mac 0.92 wrapper is not this mobile release.
