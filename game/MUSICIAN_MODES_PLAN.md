# Утверждённое распределение музыкальных режимов

Решение пользователя от 2026-09-09. Статус: спецификация для внедрения;
это не описание уже опубликованной версии игры.

## The Trumpeter — Scale Palette

Заменяет прежний режим трубача с голосовым запросом basic/guide/color tones
и сбором летающих цифр. Голосовой запрос больше не является частью задания.

- Звучит аккорд, на экране остаются его обозначение и заданная окраска/контекст.
- Игрок выбирает несколько подходящих гамм, затем подтверждает набор кнопкой Check.
- Каждая гамма подписана с её тоникой, например D Dorian, D Minor Pentatonic.
- Прослушивание варианта отдельно от его выбора: короткая фраза поверх аккорда.
- Ответы должны соответствовать конкретной окраске и гармоническому контексту;
  нельзя объявлять все остальные способы импровизации музыкально неверными.
- Проверенные примеры хранят допустимые ответы явно. Не выводить их только
  из совпадения наборов высот: пентатоника может содержать лишь часть звуков.
- Основной источник для подготовки примеров:
  https://online.berklee.edu/takenote/jazz-improvisation-10-scales/
  Дополнительный контекст:
  https://www.berklee.edu/berklee-today/summer-2004/Wayne-Naus

## Vibraphonist — Color Hearing

Развитие идеи Top Note: определить все реально звучащие надстройки,
а не только одну верхнюю ноту и не потенциально допустимые надстройки.

- Beginner: персонаж не появляется.
- Student: одна надстройка.
- Master: одна или две надстройки.
- Legend: случайно одна, две или три надстройки.
- Аккорд звучит вертикально; показывается основа, например Cm7.
- Панель: ♭9, 9, ♯9, 11, ♯11, ♭13, 13.
- Отметки переключаются нажатием; Check проверяет весь набор целиком.
- Показывать число искомых надстроек; Listen / Space повторяет тот же аккорд.
- Две попытки, после первой ошибки не раскрывать правильный набор.
- После верного ответа отдельно проиграть надстройки, затем полный аккорд.
- Каждый пример содержит явные ноты расположения и метки ответа; воспроизведение
  и проверка используют один объект данных. Надстройки сначала в верхнем регистре.
- Утверждённая иллюстрация: design-concepts/vibraphonist-flight-woman-v2.png.

## Состояние кода при фиксации

В expedition.mjs трубач пока запускает kind=tones, toneMission/makeToneNumbers
и audio.announce. Это старый режим, подлежащий замене. Color Hearing пока
не подключён. При внедрении нужны отдельные типы заданий и отдельное состояние
множественного выбора, чтобы смена артефакта полностью завершала предыдущее задание.

## Проверка перед выпуском

- Правильный и неправильный набор, снятие отметки, две попытки, повтор звука.
- Ответ во время звучания без устаревших аудиоколбэков после смены режима.
- Отсутствие вибрафонистки на Beginner и правильное число надстроек по сложности.
- Телефон и десктоп: кнопки доступны, поле задания заменяет предыдущий режим.
- Проверки проекта и браузер, затем новая версия PWA-кэша и проверка опубликованных файлов.
