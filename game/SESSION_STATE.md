# Space Music College — сохранённое состояние

Обновлено: 2026-09-11. Этот файл хранит договорённости независимо от того,
показывает ли приложение Codex всю старую ленту и изображения.

## Текущая сборка

- Текущий рабочий выпуск: BUILD 070.
- Публичная игра после публикации: `https://timurkoksharoff-bebop.github.io/reharm-ear-trainer/game/?release=070`
- Основной полёт работает в Safari через классический `game.bundle.js`.
- В Book Flight ответы «ступень + тип аккорда» объединены в одну плашку.
- Есть 16 глав/карт миссий, вертикальные аккорды, короткое перемирие во время
  предъявления маршрута и повтор Space: одна нота HOME + текущий аккорд.
- Есть магазин, накопительная валюта, корабли и улучшения.
- Есть режимы гитариста, клавишника, барабанщика и Drum Machine с рудиментами.
- В Melody Memory реально добавлены: Afro Blue, All the Things You Are,
  Autumn Leaves и Blue Bossa плюс прежние учебные мелодии.
- Полёт теперь по умолчанию продолжается визуально под компактной полупрозрачной
  панелью ответов. Корабль физически не заходит под неё; `?deck=0` временно
  оставлен только для сравнения со старой компоновкой.
- Подсказка и повтор перенесены в узкую правую колонку, плашки ответов уменьшены.
- Только полноценные музыкальные артефакты открывают отдельную камеру: обычная
  победа над аккордом больше не вызывает случайного музыканта. На поле лежит
  уменьшенная авторская иллюстрация без подписей `GTR`, `KEY` и других заглушек.
- Rock Tongue теперь вращает барабан внутри нарисованного автомата, замедляется и случайно выбирает
  Guitar Pilot, Key Pilot, Jazz Bass, Chord Recovery, Drum Machine, Trumpeter
  или The Drummer.
- В начале каждого задания действует 3,5 секунды перемирия, чтобы прослушивание
  не отнимало щит. Постоянно паузовые сцены музыкантов по-прежнему держат бой.
- Артефакты добавлены и в Book Flight; 16 учебных глав больше не состоят только
  из гидр. Студент и Новичок слышат гитарные лады только вверх, Master и Legend —
  вверх или вниз.
- Щит отображается батареей с числом HP и красной аварийной индикацией. Успешные
  музыкальные испытания восстанавливают HP, а попадание явно показывает потерю.
- По мере прогресса появляются стационарные боковые турели: они наводятся на
  корабль, стреляют и уничтожаются автоматическим огнём.
- Высота приложения берётся из реального `visualViewport`, поэтому панель Safari
  не обрезает нижние ответы. Панель ответов ужата и остаётся полупрозрачной поверх
  непрерывного игрового поля; подсказка и повтор стоят в узкой боковой колонке.
- «Слуховой полигон» повторяет игровую механику: тоника, затем полный аккорд и
  одна готовая плашка «ступень + тип». По умолчанию аккорд вертикальный; отдельно
  включаются арпеджио вверх и вниз. После провала полёта показана последняя гидра.
- Резервный таймер английской голосовой команды увеличен: Safari больше не
  должен обрезать фразу перед словами `color tones`.

## Вибрафонистка

- Текущий утверждённый для игры кадр:
  `assets/vibraphonist.png`.
- Его исходная генерация:
  `exec-97f6234a-38de-449e-b54a-e4ea09cf0280.png`.
- Исходник с тремя стержнями для будущей точной правки:
  `design-concepts/vibraphonist-grip-source-three-sticks.png`.
- Его не использовать в игре до исправления: в каждой кисти должны остаться две
  колотушки; указательный палец лежит поверх стержней и закрывает перекрестие;
  одна палка выходит между указательным и средним пальцами, вторую прижимает
  большой палец. Никакого «букета» из двух палок в одном зажиме.
- Режим Vibraphonist — Color Hearing: Student слышит одну надстройку, Master
  одну или две, Legend одну, две или три; варианты ♭9, 9, ♯9, 11, ♯11, ♭13, 13;
  две попытки, после первой ошибки ответ не раскрывается.

## Визуальное направление

Суровый обжитой космос: потёртые ящики, заклёпки, масло, патина, провода,
динамики, лампы, фейдеры и ремонтные заплаты. Избегать золочёной сказочности,
глянца и несвязанных прямоугольных «фотографий поверх игры». Сцены музыкантов
должны закрывать игровое поле единым концертным фоном.

## Правки после просмотра BUILD 065

- Барабанщицу в горизонтальном окне показывать целиком: портретный кадр кладётся
  поверх затемнённого продолжения того же космического фона, без обрезанной головы.
- Заголовки `MELODY MEMORY`, `DRUM MACHINE` и других музыкальных пауз выводить
  прямо поверх сцены с тенью, без чёрной прямоугольной подложки.
- Магистр начинает с трезвучий, септаккордов, sus и dim. Одиночные надстройки
  подключаются после двух маршрутов, двойные альтерации — после пяти.
- Фактуру кнопок проверить на десктопе и телефоне: все варианты ответа должны
  выглядеть как нажимаемые металлические клавиши с винтами, без плоских заглушек.
- Парадидлы остаются отдельной школой аппликатуры и акцентов. Добавить отдельный
  банк `Rhythm Cells`: четверти и восьмые, восьмая + две шестнадцатых, две
  шестнадцатых + восьмая, пунктир, паузы, синкопы и swing; усложнение по уровням.

## BUILD 070 — Jazz 1460 / импорт / тональности

- Доступ: SOUND LAB → STANDARDS → OPEN; либо MISSIONS → GALACTIC TOUR.
- Встроен компактный каталог всех 1460 цифровок из пользовательского Jazz 1460.html.
  Мелодии из него не извлекаются: это отдельный режим полёта по гармонии.
- Поиск по названию/автору, выбор любой из 12 тональностей и уровня пилота,
  предпросмотр по тактам, прослушивание первых восьми аккордов, запуск в полёт.
- 1085 карт допускаются к запуску текущим парсером. Это число технически
  разобранных карт, НЕ заявление о музыкальной проверке всех стандартов.
  Остальные 375 остаются в поиске с диагностикой и без кнопки запуска.
- Поддержаны обычные повторы, первая/вторая вольты iReal, повторы одного такта,
  отдельные басы обращений. Неразобранные D.C./D.S./Coda, двухтактовые повторы,
  N.C., неизвестные качества не упрощаются: карта блокируется с объяснением.
- Импорт одного стандарта из iReal HTML или несжатого MusicXML .xml/.musicxml
  с одной партией harmony. Свои файлы сохраняются локально в браузере.
  Полёт использует последовательность гармонических событий, не нотный ритм:
  одна гидра на аккорд. MXL, многопартийные harmony и сложная XML-форма ещё не поддержаны.
- Исправлены неверная перестановка символов irealb и обработка XML kind text.
  Два реальных файла Autumn Leaves совпадают по всем 32 тактам / 34 аккордам,
  root, quality, intervals и slash bass. Исходники остаются вне Git.
- Проверены все 12 транспозиций и независимый slash bass в звуке и ответах.
  Импортированные интервалы не расширяют и не меняют канонический книжный каталог.
- В браузере проверены поиск Autumn Leaves, транспозиция G minor → D minor,
  старт 34 гидр, возврат после поражения, загрузка MusicXML через file picker.
  Размер телефона 390×844. В меню нижняя боевая панель скрыта и не перекрывает кнопки.
- Доступные check, expedition-check, audio-check, assets-check, importer-check
  и сборка должны пройти перед публикацией; tests/smoke.cjs в этом worktree отсутствует.
- Следующие задачи: сложная форма оставшихся карт; затем Vibraphonist Color
  Hearing и Trumpeter Scale Palette. Их привязка к текущему стандарту ещё не готова.
  Текущие артефакты в туре появляются, но их задания пока используют прежние банки.
