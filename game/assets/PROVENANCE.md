# Original game art

All four PNG assets were generated specifically for Flight 001 using the built-in
ImageGen tool on 2026-09-07. No Trainer, bear, Arranger or third-party game asset
was altered. Source PNGs retain their generated transparency. The three sprites are 1254×1254; terrain is 1024×1536;
Canvas displays them at gameplay size. No external network asset is used.

## hydra.png prompt

Use case: stylized-concept. Original 2D arcade video game enemy sprite, rendered
in game at approximately 180 by 150 pixels. A symmetrical three-headed robotic
space hydra, all three angular dragon-like mechanical heads clearly separated,
attached to one compact broad body, facing and aimed downward on the screen.
Angular dark aubergine armour, luminous coral-pink eyes and central reactor,
cool lavender edge highlights. Strong instantly readable silhouette with thick
angular shapes. Crisp subtly pixel/arcade inspired 2D painted bitmap sprite with
restrained geometric shading, original design with no existing franchise influence.
Single centered isolated whole object, square canvas, about 80% width and height,
front/top view aimed down screen, no cropping, bilateral symmetry. Truly transparent
background with alpha channel. Exactly one three-headed hydra, no text, logo, UI,
border, rectangular shadow, stars, particles, scene, ground, painted checkerboard.

## ship.png prompt

Use case: stylized-concept. Original 2D arcade video game player spaceship sprite,
rendered in game at approximately 48 by 64 pixels. One small sleek player spaceship
seen exactly top down, long nose pointing straight upward, compact symmetrical
swept wings, ivory and pale cyan hull, dark indigo cockpit, turquoise exhaust
pointing downward from the rear. Strong instantly readable silhouette with bold
angular shapes. Crisp subtly pixel/arcade inspired 2D painted bitmap sprite with
restrained geometric shading, original design with no existing franchise influence.
Single centered isolated whole object, square canvas, ship and exhaust about 80%
height, narrower width, no cropping, bilateral symmetry. Nose straight up, exhaust
straight down. Truly transparent background with alpha channel. Exactly one ship,
no text, logo, UI, border, rectangular shadow, stars, particles, scene, ground or
painted checkerboard. Readable at tiny size.

## terrain.png prompt

Original seamless vertically tileable top-down alien orbital ruin terrain, portrait
1024×1536. Deep indigo and oxidized turquoise mechanical canyon, layered platforms,
sparse amber/cyan lights, intricate microdetails on left and right, broad calm
central corridor. Crisp pixel-inspired painted arcade surface. No perspective
horizon, ships, enemies, text, UI or logo. Top and bottom should connect.

The resulting top/bottom mechanical geometry is imperfectly matched; see DESIGN.

## drone.png prompt

Original compact small interceptor, top-down facing downward, chunky angular
coral/copper hull, dark purple center, one amber core, paired swept wings and a
strong silhouette at approximately 28 pixels. Transparent background; no scene,
text or shadow.

All four outputs were visually inspected. No source images from Zanac were used.

## Flight 003 musician assets

Built-in ImageGen created four original fictional, full-body transparent PNGs on
2026-09-08: `trumpeter.png`, `keytarist.png`, `guitarist.png` and `drummer.png`.
The prompts specify weathered working musicians in worn orbital flight gear; no
real-person likeness was requested. The game uses them only after a small relic
is captured. Relics themselves are deterministic Canvas drawings.

`keytar-exact.svg` and `guitar-exact.svg` are hand-authored vector overlays. The
keytar has fourteen equal white keys with black-key groups 2–3–2–3. The guitar
overlay has exactly six strings and six tuning pegs, with single markers at 5, 7,
10, 15, 17, 19 and 21 and a double marker at 12. These overlays prevent generative
geometry from becoming the musical reference.
