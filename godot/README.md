# EAR YOGA — тестовый перенос на Godot

Экспериментальная ветка `codex/ear-yoga-godot-prototype`, версия прототипа 0.1.
Эталон — `ear-yoga-v1.36-checkpoint` (10cd426). Публичная PWA продолжает
работать по прежнему адресу. Файлы `garden/` и `game/` не менялись.

## Запуск

Нужен [Godot 4.5.2 Standard](https://godotengine.org/download/archive/4.5.2-stable/)
и Node.js 22 или новее. .NET не требуется. Клон должен содержать `garden/`
и `game/`, поскольку музыкальные данные и утверждённые ресурсы берутся из 1.36.

Из корня репозитория:

```sh
node godot/tools/prepare.mjs
godot --editor --path godot
```

На Mac можно открыть `godot/project.godot` в Godot после подготовки и нажать
F6/F5 для запуска. Или выполнить `godot/Запустить прототип.command`.
Если Godot установлен вне `/Applications`, задать `GODOT_BIN` — полный путь
до его исполняемого файла. Рендерер — Compatibility для Intel Mac.

Выбрать маршрут, режим и нажать «Старт». Стрелки/WASD двигают Лотос;
в игровой области также работает перетаскивание мышью/пальцем. ROOT внизу,
тип аккорда справа, отдельный BASS слева на маршрутах с обращениями.
Пробел/Esc или кнопка ставят полёт на паузу. Переключение окна тоже ставит
игру на паузу; продолжение — вручную. ↻ начинает текущий маршрут заново.

## Что перенесено

- Пять исходных маршрутов: Fig. 1.6, 1.7, 1.9, 16.4 и длинная Fig. 4.2.
  Сохранены все позиции, повторы, тоника, типы и slash bass.
- Режимы «Студент» (корень/тип) и «Преподаватель» (корень/тип/бас),
  автоматическое открытие совпадающего с корнем баса, сохранение найденных
  частей при ошибке, завершение и последующее прослушивание.
- 100 за часть, −25 за ошибку, ограниченные бонусы за тоны, исходная формула
  бонуса времени, заморозка счёта и времени после завершения.
- Четыре ресурса, отдельный Teacher O₂, исходная таблица допустимых тонов,
  нормирование кислорода на длину маршрута, окно 180 мс, rescue 3.5 секунды.
- Небольшая тестовая сцена с оригинальными фоном, Лотосом и иконкой,
  управлением, подбором тонов и базовыми ресурсными предметами.
- Отдельные локальные рекорды Godot. Данные PWA не читаются и не меняются.

## Архитектура

```text
core/mission.gd                 независимые правила задания и счёта
planets/ear_yoga/flight_state.gd состояние полёта, O₂ и ресурсов этой планеты
planets/ear_yoga/game.gd         сборка сцены, UI и ввод
platform/audio_transport.gd     воспроизведение и часы звука
platform/local_records.gd       версионированное отдельное хранилище
data/routes.json               снимок точных данных из исходников 1.36
tools/prepare.mjs               воспроизводимая подготовка без npm-пакетов
checks/                        сравнение с 1.36 и проверки сцены
```

Общее ядро не знает про корабль, цветы или кислород. Следующая планета может
использовать другие правила и сцену. Нет единого класса со всеми механиками
всех будущих миров. Аудио и сохранения заменяются отдельно от правил задания.

Время звучащего WAV с поправкой на буфер и выходную задержку управляет
положением маршрута. Независимый Timer не переключает аккорды. Источник:
[документация Godot о синхронизации с аудио](https://docs.godotengine.org/en/4.5/tutorials/audio/sync_with_audio.html).
При паузе приостанавливается тот же поток; возобновление сохраняет позицию.

`prepare.mjs` читает текущий каталог и музыкальные функции 1.36, экспортирует
точные MIDI, написание аккордов и verdict каждого из 12 тонов. Проверка
`--check` выявляет изменение исходников или расхождение снимка. Это адаптер
для ограниченного среза: полноценный редактор гармонии в GDScript пока не
перенесён. Новые задания не синтезируются из приблизительных распознаваний.

## Звук и границы прототипа

Подготовка рендерит Felt Piano из трёх существующих WAV: те же MIDI,
регистры, ближайшие семплы, pitch ratio, удаление начальной тишины и
относительные уровни голосов. WAV содержит тонику один раз и зацикливаемый
маршрут. Подготовленные WAV и копии изображений игнорируются Git и
воспроизводятся командой подготовки; исходные семплы уже есть в репозитории.

Это тест архитектуры, а не полная версия 1.36: остальные тембры, Web Audio
EQ/компрессор, точный WebGL-рендерер, цветы аранжировки, артефакты, полный
набор опасностей, редактор маршрутов, меню, обучение и запись видео пока не
перенесены. Расстановка ресурсных предметов упрощена для тестовой сцены.
Характер Felt Piano взят из исходных семплов; акустическая идентичность
Web Audio ещё требует прослушивания и сравнения. Нарастающий рассинхрон
существующей видеозаписи PWA этим прототипом не исправляется.

Нет iOS-проекта, подписи, экспорта в App Store или публикации новой PWA.
Проверки размеров окна на Mac не считаются проверкой настоящего iPhone.
Для следующего этапа нужны прослушивание пользователем, сравнение полёта
и измерение аудио на реальном целевом устройстве.

## Проверки

```sh
node godot/tools/prepare.mjs --check
godot --headless --path godot --script res://checks/run_checks.gd
EAR_YOGA_QA_DIR=/tmp/ear-yoga-qa godot --path godot --audio-driver Dummy -- --smoke
```

Скрипт правил воспроизводит 360 состояний JavaScript-эталона: ответы,
ошибки, пауза, запрет ответа на паузе, автоматический бас, завершение,
бонус времени и рестарт; дополнительно проверяет O₂ и защиту от фарма.
Проверка сцены запускает реальный рендерер и звуковые часы с Dummy-выходом,
нажимает UI, проверяет ввод и сохраняет снимки разных размеров окна.
Она не подтверждает качество слышимого звука или работу на iPhone.

На этой ветке предусмотрен отдельный GitHub Actions workflow для тех же
проверок. Он не публикует GitHub Pages.
